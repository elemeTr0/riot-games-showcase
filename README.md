# Riot Games Showcase

A portfolio-style website inspired by Riot Games, showcasing the company's history, games, esports, and latest news.

## Features

- Interactive game slider
- Animated navigation
- Responsive layout
- Game descriptions
- News cards
- Team information modal

## Built With

- HTML5
- CSS3
- JavaScript

## Purpose

This project was created to practice front-end development, UI design, and JavaScript interactivity.
